# Fuentes locales

La instalación institucional utiliza la familia Humanist 521 BT. Los archivos de fuentes no se publican en este repositorio.

Para la generación de documentos, coloque aquí los archivos TTF correspondientes que tenga derecho a utilizar. El programa los registra en el perfil del usuario de Windows antes de exportar con Word.

La interfaz usa Open Sans si está disponible o Segoe UI como alternativa. Puede abrirse sin las fuentes de los certificados.
