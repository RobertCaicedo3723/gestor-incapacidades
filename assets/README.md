# Recursos visuales locales

Los logos e iconos institucionales se excluyen de esta publicación. La aplicación puede abrirse sin el logo: muestra una cabecera de texto como alternativa.

Una instalación autorizada puede aportar `uis-oficial.png` para la cabecera y `uis.ico` para el ejecutable. Estos recursos no se redistribuyen bajo la licencia MIT del código.
